# Analisis comparativo entre los codigos "Eigenfaces", "Fisherfaces" y "LBPH"

### Indicaciones.

Mediante un DATASET **(Aconsejable que cuenten con diferentes tipos de luz)**, analizar los siguientes codigos: 1.- **Eigenfaces**, 2.- **Fisherfaces** y 3.- **LBPH**; para observar su forma de trabajo con el mismo dataset.
